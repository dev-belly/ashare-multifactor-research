# 方法论与时间顺序

这份说明描述当前代码已经实现的口径，也明确列出尚未模拟的部分。

## 1. 数据与可得时间

- 合成模式使用固定随机种子和工作日近似交易日历。
- AkShare 模式不静默切换数据源；失败、部分覆盖或显式降级都会记录在结果 metadata 中。
- 财务字段在 `available_date = publish_date + financial_lag_days` 后才可用于因子计算，默认安全缓冲为 90 个自然日。
- EP、BP、SP 和换手率使用该日之前最新已披露的股本，不用期末最新股本回填历史。

!!! note "AkShare 的当前边界"
    AkShare 完整时点财务报表尚未标准化，因此严格模式当前会失败。`allow_partial_real_data: true` 只适合行情与技术因子实验，并标记为 `akshare_partial`。

## 2. 标签与 fold 净化

监督学习标签定义为同一只股票从信号日之后开始的 21 个交易日复合收益：

```text
y(T) = Π(1 + r(T+1) ... 1 + r(T+21)) - 1
```

每只股票独立计算，尾部不足 21 个观测时标签为空。每个扩张窗口 fold 训练前，还会剔除测试期开始前最后 21 个训练交易日，避免这些标签包含测试期收益。

当前 OOS 切分只支持按年扩张：训练窗口逐年增加，测试窗口不参与该 fold 的拟合。

`results.json` 的 `meta.model_oos_coverage` 按模型记录每个 fold 的成功或失败状态、失败原因、预期与实际打分日期数及覆盖率。覆盖率分母是配置 OOS fold 中实际存在于因子面板的交易日，不是自然日。只要某模型至少一个 fold 成功，部分失败会保留并明确披露；若一个成功 fold 都没有，流水线会直接失败，不会把该模型静默从结果中删掉。

## 3. 因子评估

- 当日因子与下一交易日收益计算 Pearson IC 和 Spearman RankIC，且因子观测只取各 fold 的 OOS 测试日期。
- 分组组合也只用 OOS 测试日期的因子和下一交易日收益；它是无成本、每日重排的诊断，不是模型策略回测。
- 因子衰减从已实现日收益按股票向后移动不同 lag 计算。
- IC 阈值只是诊断线索；样本数、稳定性、多重检验和经济含义都需要一起判断。

## 4. 组合执行

```text
T 日收盘后得到 score
        ↓
T+1 交易日收盘执行目标权重并扣成本
        ↓
从 T+1 收盘之后的区间开始承担收益，持有期间权重自然漂移
        ↓
下次信号后的下一交易日收盘再调仓（最短持有期默认等于所选调仓频率）
```

Top-K 组合默认等权、满仓，并受 5% 单股权重上限约束。因此 `top_k` 至少为 20，而且每个有效调仓截面也必须有至少 20 只可选股票；条件不满足时会明确失败，不会用未披露的现金仓位稀释收益和风险。成本口径为：

```text
cost = Σ |target_weight - current_weight| × cost_bps × 1e-4
```

这里的 `cost_bps` 是单边费率；买入和卖出权重都会进入绝对权重变化总和。

净值日历从首个有效分数日延伸到可用收益日历末尾：最后一个有效分数日之后不再生成新信号，但已经建立的持仓仍继续计入真实发生的尾部收益。每个模型的最后打分日、回测收益起止日和尾部日期数也记录在 `meta.model_oos_coverage`，避免把“有净值”误解为“每天都有新模型分数”。

## 5. 对照与统计

- `benchmark` 是同一股票池的每日等权、无成本净值，不是沪深 300 可投资全收益指数。
- 模型净值、年化收益、波动、Sharpe、最大回撤、Calmar 和换手统计均来自样本外回测区间。
- 成本敏感性分别重跑配置中的 0/10/20/30 bps 场景。
- 市况稳健性先由股票池等权净值划分 regime，再用完整日净值计算各阶段收益。

## 6. 当前未模拟

- 历史指数成分、退市证券和完整 ST 名单；
- 涨跌停与停牌时无法按目标权重成交；
- 开盘成交、冲击成本、滑点、印花税和容量；
- 融券可得性与做空约束；
- 可投资指数全收益基准。

因此，结果应作为研究流程诊断，而不是实盘收益承诺。
