# FactorLab

FactorLab 是一个用于检查多因子研究流程的 A 股研究项目，覆盖数据加载、时点一致因子、净化的扩张窗口样本外验证、组合回测和浏览器报告。

!!! warning "先看数据来源"
    默认配置使用确定性合成数据，只用于验证代码和研究流程，不代表真实市场收益，也不能证明存在可投资 Alpha。

## 当前状态

- 默认数据源为 `synthetic`，无需联网即可复现。
- AkShare 行情、交易日历、股票池和行业映射已有来源与覆盖率记录。
- 完整的 AkShare 时点财务字段尚未标准化；严格模式会明确失败，不会把部分数据伪装成完整实盘回测。
- 公共仪表盘只读；重新运行与重载接口需要服务端令牌。
- 结果包含一个同期全股票池每日等权、无成本基准，用于区分市场 Beta 与策略表现。

## 流程

```text
synthetic / 显式 AkShare 模式
        ↓
清洗、交易日历对齐、来源记录
        ↓
16 个时点一致因子
        ↓
21 日标签 + fold 边界净化
        ↓
expanding-window OOS 训练与预测
        ↓
下一交易日收盘执行、权重漂移、交易成本
        ↓
IC、分组、衰减、市况、基准与 HTML 报告
```

## 解读原则

查看任何结果前，至少核对：

1. `meta.actual_data_source` 与 `meta.data_load`；
2. 策略是否真正跑出样本外分数；
3. 策略相对 `benchmark` 的表现，而不是只看绝对收益；
4. 成本、调仓频率和当前未模拟的交易约束。

本项目仅供研究与教学，不构成投资建议。
